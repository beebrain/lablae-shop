# ร้านลับแลของฝาก (ร้านตัวอย่าง)

หน้าร้านบนมือถือของร้านสมมติในอำเภอลับแล จังหวัดอุตรดิตถ์ ใช้เป็นตัวอย่างตลอดวิชา 3603403
โปรแกรมอุปกรณ์สื่อสารเคลื่อนที่ทางธุรกิจดิจิทัล เป็นฉบับสุดท้ายของบทที่ 8

เปิดบนมือถือ: https://beebrain.github.io/lablae-shop/

ความสามารถ: รายการสินค้าจากอาร์เรย์ ตะกร้าที่จำค่าได้ QR พร้อมเพย์ตามยอด ส่งออเดอร์ทาง LINE โทรหาร้าน นำทาง แนบสลิป ติดตั้งบนจอโฮม (PWA) และนโยบายความเป็นส่วนตัว

เบอร์โทร เบอร์พร้อมเพย์ และ LINE ID เป็นข้อมูลสมมติ อย่าโอนเงินจริง

โค้ดตั้งต้นของผู้เรียน: https://github.com/beebrain/mobile-lab-starter
